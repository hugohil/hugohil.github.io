Rendu et projet final

Présentation du projet intermédiaire, puis lancement du projet final.

Format de présentation

Prototype présenté en direct, 5 minutes maximum.

01

L'intention ; ce que vous vouliez construire.

02

La démonstration ; montrez le projet en fonctionnement. Sachez dans quel ordre montrer les choses, ayez des valeurs intéressantes en tête.

03

Le code ; montrez les variables principales, les blocs importants, ...

04

La suite ; ce que vous feriez avec plus de temps, ou différemment avec le recul.

Si une ligne vient d'ailleurs et que vous ne savez pas l'expliquer, dites-le. Ne pas savoir n'est pas un problème, faire semblant oui.

Critique collective

Prenez des notes pendant les passages. Pour chaque prototype : une chose qui fonctionne, une piste à explorer. On critique le système, pas la personne. Et on évite les « j'aime bien » : dites ce que vous voyez.

Critères :

  • Intention
  • Lisibilité du système
  • Maîtrise du code
  • Rendu visuel

Echantillonner l'image

let img;
let stepSize = 12;

async function setup() {
  img = await loadImage('image.jpg');
  createCanvas(img.width, img.height);
  img.loadPixels();
  noLoop();
}

function draw() {
  background(255);
  noStroke();
  fill(0);

  for (let x = 0; x < width; x += stepSize) {
    for (let y = 0; y < height; y += stepSize) {
      let c = img.get(x, y);
      let mean = (c[0] + c[1] + c[2]) / 3;        // moyenne de R, G et B
      let taille = map(mean, 0, 255, stepSize, 0);      // sombre = grand point
      circle(x, y, taille);
    }
  }
}

  let word = 'HELLO';

    let x = map(i, 0, word.length - 1, 80, width - 80);

    text(word[i], x, y);
  }
}

push et pop

Régulièrement, on va vouloir déplacer le repère.

function setup() {
  createCanvas(400, 400);
}

function draw() {
  background(220);

  rect(-50, -50, 100, 100);

  push(); // on sort de l'état de base
  translate(width/2, height/2); // l'origine (0,0) se déplace ici
  rotate(PI / 4); // rotation autour de la nouvelle origine
  scale(2);
  rect(-50, -50, 100, 100);
  pop(); // on revient dans l'état de base
}

Sans pop() les transformations vont se cumuler : chaque translate() part du repère déjà déplacé par le précédent.

// les positions s'additionnent
for (let i = 0; i < 5; i++) {
  translate(80, 20);   // (80,20) puis (160,40) puis (240,60) ...
  circle(0, 0, 40);
}

C'est parfois ce qu'on veut, mais pour que chaque élément parte du même repère, il faut l'isoler :

for (let i = 0; i < 5; i++) {
  push();
  translate(80 + i * 100, 200);
  rotate(i * 0.3);
  rect(0, 0, 60, 60);
  pop();
}
push()mémorise le repère et les styles
pop()revient à l'état mémorisé
translate(x, y)déplace l'origine
rotate(a)tourne le repère ; angle en radians
scale(n)agrandit ou réduit

push() sauvegarde aussi fill(), stroke(), strokeWeight(), rectMode(), textSize()… Un fill() posé entre un push() et un pop() disparaît au pop().

Boucle parfaite

expliquez le code ci-dessous
  • vous devez expliquer le fonctionnement du code ci-dessous
  • vous commenterez où c'est nécessaire
  • l'écriture de ces commentaires par une IA est interdite
  • si vous ne connaissez pas une function, allez chercher dans la doc de p5
  • si vous voulez vérifier le fonctionnement d'un paramètre, isolez-le
let duration = 240; // cycle en fps
let cols = 6;
let rows = 6;
let noiseRadius = 0.5;
let vamp = 0.2;
let ramp = 2;

function setup() {
  createCanvas(600, 600);
  rectMode(CENTER);
  noStroke();
  fill(20);
}

function draw() {
  background(242);

  let t = (frameCount % duration) / duration;
  let angle = t * TWO_PI;

  let cw = width / cols;
  let ch = height / rows;

  for (let i = 0; i < cols; i++) {
    for (let j = 0; j < rows; j++) {

      let nx = cos(angle) * noiseRadius + i * 10;
      let ny = sin(angle) * noiseRadius + j * 10;
      let n = noise(nx, ny);
      
      let phase = (i + j);
      let offset = sin(angle + phase) * ch * vamp;
      
      let x = i * cw + cw / 2;
      let y = j * ch + ch / 2 + offset;

      let len = map(n, 0, 1, cw * 0.2, cw * 0.8);

      let rotation = angle * n * ramp;

      push();
      translate(x, y);
      rotate(rotation);
      rect(0, 0, len, ch * 0.1);
      pop();
    }
  }

  // repère dans le cycle
  rect(t * width, height - 4, 4, 8);
}
