Les entités HTML

→ pour écrire des caractères réservés, invisibles ou difficiles à taper au clavier

Une entité commence par & et finit par ;. Elle s'écrit soit avec un nom (&nbsp;), soit avec un numéro (&#8239;). Elles ont l'inconvénient de rendre votre HTML plus difficile à lire.

&lt; &gt;< et > ; pour afficher un chevron sans qu'il soit interprété comme un élément d'une balise
&amp;& ; esperluette se dit ampersand en anglais
&nbsp;Espace insécable
&#8239;Espace fine insécable (cf. Wikipédia)
&thinsp;Espace fine, mais sécable.
&rarr; &hellip; &copy;→ … © ; flèches, points de suspension, symboles…
<p>Vous êtes prêts&#8239;? On y va&#8239;!</p>
<p>&laquo;&#8239;Bonjour&#8239;&raquo;, dit-elle.</p>
<p>Ce fichier pèse 12&nbsp;Mo.</p>

Vous avez une liste des caractères disponibles sur Wikipédia.

Entités et fonte

Une entité est un caractère, donc il faut que la police ait le glyphe. Si votre font ne contient pas un symbole, le navigateur va le chercher dans les polices suivantes de font-family, puis dans les polices du système. Le rendu change alors d'un ordinateur à l'autre, et peut même s'afficher comme un carré vide (« tofu »). Pour garder le contrôle, on peut ajouter en fallback une police dédiée aux symboles, comme Noto Sans Symbols :

@import url('https://fonts.googleapis.com/css2?family=Noto+Sans+Symbols&family=Noto+Sans+Symbols+2&display=swap');

body {
  /* si un caractère manque dans "Ma Police", on essaie les polices suivantes */
  font-family: 'Ma Police', 'Noto Sans Symbols', 'Noto Sans Symbols 2', sans-serif;
}

Retour à la ligne avec text-wrap

→ contrôler la façon dont le navigateur coupe les lignes d'un texte (cf. MDN)

/* retour à la ligne automatique (valeur par défaut) */
p {
  text-wrap: wrap;
}

/* empêche le retour à la ligne automatique */
p {
  text-wrap: nowrap;
}

/* équilibre la longueur des lignes */
h1, h2 {
  text-wrap: balance;
}

/* évite les orphelines */
p {
  text-wrap: pretty;
}

Les Pseudo-classes CSS

→ permet de modifier le style d'un élément en fonction de son état

/* le style suivant ne sera appliqué que lorsqu'un lien sera survolé */
a:hover {
	font-weight: bold;
}
/* cible une image lorsque son parent est survolé */
div:hover a {
	border: 1px solid black;
}
/* cible tous les paragraphes pairs (1 liens sur 2) */
p:nth-child(odd) {
	background-color: light-grey;
}

Transitions CSS

→ Transition fluides lors du changement d'état d'un élément

/* Transition simple sur le survol d'un élément */
.button {
  background-color: blue;
  transition: background-color 0.5s ease;
}

.button:hover {
  background-color: red;
}

/* Transition multiple (couleur et transformation) */
.icon {
  color: black;
  transform: scale(1);
  transition: color 0.3s ease, transform 0.3s ease;
}

.icon:hover {
  color: green;
  transform: scale(1.2);
}

Media Queries

→ Pour adapter son design à différentes tailles d'écran

/* Style de base pour mobile */
.container {
  background-color: lightblue;
}

/* Changement de style pour les écrans > 1280px */
@media (min-width: 1280px) {
  .container {
    background-color: coral;
  }
}

/* Changement de style pour les écrans < 600px */
@media (max-width: 600px) {
  .container {
    background-color: pink;
  }
}
