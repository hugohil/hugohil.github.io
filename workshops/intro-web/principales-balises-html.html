Principales balises HTML

<!DOCTYPE>Déclare le type de document ; En début de fichier HTML. Exemple : <!DOCTYPE html>
<html>Balise racine pour un document HTML. Exemple : <html></html>
<head>Contient les métadonnées et liens. Exemple : <head></head>
<title>Définit le titre de la page ; Dans la balise <head>. Exemple : <title>Mon titre</title>
<body>Contient le contenu visible de la page. Exemple : <body></body>
<h1>, <h2>, ...Balises de titre ; De <h1> à <h6>. Exemple : <h1>Titre</h1>
<p>Paragraphe. Exemple : <p>Texte ici</p>
<a>Lien hypertexte ; Utilise l'attribut href. Exemple : <a href="https://example.com">Lien</a>
<img>Image ; Utilise les attributs src et alt. Exemple : <img src="image.jpg" alt="Description">
<ul>Liste non ordonnée. Exemple : <ul><li>Élément</li></ul>
<ol>Liste ordonnée. Exemple : <ol><li>Élément</li></ol>
<li>Élément de liste ; Utilisé dans <ul> ou <ol>. Exemple : <li>Élément</li>
<div>Division ou section ; Utilisé pour le layout. Exemple : <div></div>
<span>Plage de texte inline. Exemple : <span>Texte</span>
<strong>Texte important ; Passe le texte en gras. Exemple : <strong>important</strong>
<em>Emphase ; Passe le texte en italique. Exemple : <em>emphasized</em>
<br>Saut de ligne ; Balise vide. Exemple : <br>
<video>Intègre un fichier vidéo ; Utilise les attributs src et souvent controls. Exemple : <video src="video.mp4" controls></video>
<audio>Intègre un fichier audio ; Utilise les attributs src et souvent controls. Exemple : <audio src="audio.mp3" controls></audio>
